Runtime

            

            
Images are never written to disk. Only job metadata and remote URLs are stored; retention cleanup runs every six hours.

            

            
Admin password

            

              
              

                
                
              

              
              
Stored as a salted scrypt hash in the database. The ADMIN_PASSWORD environment value remains a recovery password.

            

            

            
Data persistence

            
Accounts, API keys, settings and job history live in DATA_DIR (Docker: /app/data). Mount a persistent volume at that path in Coolify so redeploys keep your data.
